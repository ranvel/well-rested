Add identity

Create the identity first, then bind it to one or more upstreams on the Upstreams page. One account that reaches many sites is one identity.

Scheme

Name the header (Authorization when blank, or e.g. x-api-key, Cookie) and type its whole value as the token, e.g. Token abc123 or session=…. A client header of the same name is replaced by it.

Dates are YYYY-MM-DD (read as 00:00 UTC), an ISO timestamp with an offset, or 30d / 12h from now.
